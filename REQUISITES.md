# libpath - Requisites <!-- omit in toc -->


## Runtime / build

**libpath** has no proper (runtime / build) dependencies outside the C
standard library and, for its C++ API, the C++ standard library.


## Development

In order to build and run the test and example programs, **libpath** needs:

* [STLSoft](https://github.com/synesissoftware/STLSoft) **1.11** or later;
* [xTests](https://github.com/synesissoftware/xTests) **0.26** or later;
